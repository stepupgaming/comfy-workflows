# Generated node SDK

```
/object_info  →  cwf snapshot  →  cwf codegen  →  typed specs
```

```sh
cwf codegen --from object_info.json -o src/nodes/gen
cwf codegen --url http://127.0.0.1:8188 -o comfy-nodes
```

Output (do not hand-edit):

| File | Role |
| ---- | ---- |
| `<category>.ts` | Specs by `/object_info` category |
| `registry.ts` | `specs` map + named exports |
| `defs.json` | Parsed defs for compile |
| `catalog.json` / `NODES.md` | Searchable catalog |
| `identifiers.json` | classType → export name |

Header says `GENERATED by comfy-workflows codegen — do not edit.`

`@stepupgaming/comfy-workflows/nodes` is the **bundled core snapshot**, not the user's custom nodes.

If a class is missing from generated files, it was missing from `/object_info`. Recapture after installing the pack and restarting Comfy. Do not invent an export name.

`--exact-combos` emits literal unions of **that machine's** files. Default codegen widens file-backed combos to `string[]` so types stay portable.

`cwf catalog [query]` searches the catalog. It does not guess.

Deeper: `_links.md` (`codegen`).
